# AI model training package

This folder contains reusable scripts for training, evaluating, explaining, and exporting the model.

Recommended order:

1. `python -m src.train_image_model ...`
2. `python -m src.train_multimodal_model ...`
3. `python -m src.evaluate ...`
4. `python -m src.export_bundle ...`

The scripts are designed to be readable so the team can explain each step.
