# Contributions and attribution

## Methods and data

- PAD-UFES-20 was created by Pacheco and colleagues; this project does not claim ownership of the dataset. See the [dataset paper](https://arxiv.org/abs/2007.00478).
- EfficientNet is an established architecture by Tan and Le. This project uses the Keras ImageNet-pretrained implementation; see the [original paper](https://arxiv.org/abs/1905.11946).
- TensorFlow/Keras, scikit-learn, Django REST Framework and React provide the underlying frameworks.

## Project work to explain

The repository contains image-only and metadata-fusion training code, patient-disjoint splitting, API preprocessing, a React interface, evaluation scripts and a documented comparison. The architecture is not a new research method.

The five-field revision restricts the clinical inputs, excludes biopsy status, aligns API preprocessing and records class-level results and failure examples. Its results are separate from the original 22-field presentation model.
